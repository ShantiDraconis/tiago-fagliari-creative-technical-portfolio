# Evidence Index — Redacted / Available Upon Request

This public repository does not include sensitive documents.

The following evidence may be provided privately, redacted where required, upon request by recruiters or hiring teams:

## Maritime & Shipboard

- Seaman’s Book showing Senior Light Tech / Senior Lighting Technician documentation
- STCW certification
- Ship Security Familiarization
- ENG1 / international medical certificate, if requested and appropriate
- Port manning / shipboard operational documentation, where shareable

## Professional

- Selected contracts or letters confirming shipboard technical roles
- Appraisals and performance feedback, redacted where needed
- References or recommendation letters, available upon request
- Selected technical documentation, where not confidential

## Portfolio Evidence

- Showreel
- Lighting and technical production photos
- Stage / venue / console / show control documentation
- Case studies
- Public creative channel metrics
- Redacted technical and creative project records

## Privacy Policy

Unredacted documents are not published publicly.

Sensitive documents are shared only with legitimate hiring teams or recruiters and only when appropriate.
